The board · 一块看板

AI 维护，
你偶尔看一眼。

左右是紧急与否，上下是重要与否，两轴交汇处是"枢"。每张卡都写明为什么放在这里。

  1. 01

    自己记

    Notice

    从你电脑上的工作记录里认出在推进的项目、做了一半的事、快到期的事，标出"停在哪、还剩什么"。

  2. 02

    自己排

    Sort

    截止日期决定紧不紧急；重要与否从你的反馈里学。日历、提醒事项和 AI 线索说的是同一件事时自动合并。

  3. 03

    你顺手校准

    Calibrate

    拖一下换象限、点一下标完成；每次改动都让它更懂你，也都能一键撤销。

Notifications · 只为要紧的事打断你

回一句话，
就算回答。

通知只发"先做"象限里的事，另外每天最多一件"可能忘了"的重要事；同一件事 12 小时内不重复，22:00–9:00 不打扰。

  • 按钮开始 / 已完成 / 稍后 / 不重要，原地生效
  • 回一句话AI 读懂成完成、改期、在等别人或新任务；状态当场生效
  • 改日期、加新任务先做成一条提议，你点"好"才写进去
  • 读不懂原样存成这件事的备注，不会丢

When to remind · 何时提醒

决定要不要提醒的，
是项目所处的阶段，
不是几天没动。

创始人把 7 条按"几天没动"试算的提醒逐条标注：它们处在完全不同的阶段，只有 2 条该发。

做成了工具，在别处使用不提醒
已完成，或被新项目取代不提醒
质量达标，先停，已有计划到计划那天提醒
卡住了，拿不定主意帮你判断怎么继续

AI 猜，你确认一次

让模型盲猜阶段，7 个只对 3 个，判错时还很自信。所以 AI 只负责发现"这个项目安静了"并给出猜测；第一次问你一句、点一下确认，写进记忆，之后不再重复问。

画像用你自己的话写

在"记忆"页写下"课程作业我都会按时交""网站寒假再说"。AI 每天 9 点后带着画像重读一遍各项目的阶段。

Data & boundaries

数据留在你的电脑上，
模型可以是你自己的。

只读本机记录

读 Codex、Claude Code 的会话和 git 提交，每 3 分钟读取一次新记录。不截屏，不记按键，不依赖第三方采集插件。

敏感信息先遮蔽

API 密钥、令牌、私钥在离开本机之前就被替换掉；密码管理器等敏感应用不采集。

模型你来选

任何兼容 OpenAI 接口的服务都能接入：DeepSeek、通义、智谱、Kimi，或经 SSH 隧道接入自部署模型。密钥只存在本机 0600 文件里。

你的清单，你点头才改

写进你自己的提醒事项和日历之前必须确认，每次写入留回执；结果不明时停下待核对，不会盲目重建。

它有自己的日历

文枢在 iCloud 里建一个"文枢"日历和一个"文枢"提醒事项列表，只在这两处直接操作，同步到你的手机。

来源当作不可信

工作记录和你的回复一律视为数据而不是指令；"忽略之前的规则……"这类话只会被记成备注。

Install

五分钟装好。

v0.6.0 是文枢的第一个发布版：四象限看板、通知与回复理解、每日按画像重读、专属日历。

下载 app Apple Silicon

  1. 从 v0.6.0 发布页 下载 Getting-Things-Done-v0.6.0-macos-arm64.zip。
  2. 解压，首次打开前把 app 移到 ~/Applications。
  3. 打开 app。app 为 ad-hoc 签名、未公证；若被拦截，在「系统设置 → 隐私与安全性」里选择「仍要打开」。

从源码安装 Intel 也可用

git clone https://github.com/zgdllt/Getting-Things-Done.git
cd Getting-Things-Done
python3 scripts/install.py
python3 ~/.codex/skills/personal-gtd/scripts/gtd.py workbench

已安装过的，用 python3 scripts/install.py --update 更新。授权读取提醒事项与日历（授权不等于批准任何任务），再为文枢建好它自己的日历和清单：

python3 ~/.codex/skills/personal-gtd/scripts/gtd.py authorize
python3 ~/.codex/skills/personal-gtd/scripts/gtd.py setup-owned

模型在 App 的 设置 → 模型供应商 里选择；不配置也能用看板和按钮。

需要

  • macOS 14+，Xcode Command Line Tools（xcode-select --install）
  • Python 3.11+，Homebrew 版本会被自动识别
  • 一个模型：任意 OpenAI 兼容接口、自部署模型，或已登录的 Codex CLI
  • 提醒事项、日历与通知权限，由 macOS 在你启用时请求

完整说明见 README；设计与验证记录见 verification.md。

上一代 · Getting Things Done

我们先做了一个"提问式"助理，第三天就没人回答了。

第一版把每条线索变成一个问题，等人逐条回答、审批。头两天处理了 110 条，第三天起几乎停了，一周后积压 249 条待办、226 个问题。文枢由此改成 AI 自己维护状态、只在要紧时提醒。上一代的工作台仍在 /classic，宣传片也保留着：两分钟宣传片 · 互动版。
