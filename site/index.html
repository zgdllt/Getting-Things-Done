The method · 受 GTD 工作法启发

大脑用来想事情，
不是用来记事情。

GTD 的五步里，最容易漏掉的是第一步。这个工具把「收集」交给电脑活动线索，其余每一步都留给你拍板。

  1. 01

    收集

    Capture

    开启 Computer History 后，活动会留下线索；也可以随手「记一下」。

  2. 02

    理清

    Clarify

    相关线索合成一张卡片，只问需要你判断的问题，原出处随时可查。

  3. 03

    组织

    Organize

    预览、确认，行动进提醒事项，固定时间进日历。

  4. 04

    回顾

    Reflect

    未处理的线索、未答的问题、逾期行动与等待事项，一页看完。

  5. 05

    执行

    Engage

    「我有二十分钟」：从真实清单里挑下一步。

From clue to commitment

线索，不是承诺。

观察到的活动只是线索：它不会自动变成任务、截止日，更不会被当作「已完成」。

  1. 线索来源Computer History 事件流、本地记忆摘要、随手记录
  2. 本地候选保留原出处片段，关联较早的相关线索
  3. 需要你判断的问题在 app 或 Codex 对话里批量回答
  4. 预览并确认你点头才写入，回执持久保存
  5. 提醒事项 · 日历正式状态以系统清单为准

Four views

四个视图，各管一件事。

原生 AppKit + 系统 WebKit。不打包 Chromium，不用前端框架、外部字体或 CDN。

◷

今天

已有提醒事项、当前与即将开始的日程、快速收集，点一下圆圈完成任务。

▤

待澄清

候选摘要、来源片段与问题。「保存答复并整理」会立刻给出回应和修订后的下一步。

◈

项目与等待

已确认的项目和它们关联的系统行动；仍在进行的等待事项。

↺

回顾

未处理线索、未答问题、逾期行动、近期日程与最近的摘要。

Data & boundaries

它能做什么，
不能做什么，写在明处。

留在本机

工作台与 SQLite 在你的 Mac 上运行；HTTP 服务只监听 127.0.0.1，写操作检查请求来源。私有数据在 ~/.codex/personal-gtd/。

会发给模型的

后台整理会把选中的活动片段、匹配的记忆摘要与系统清单上下文发给你现有的 Codex CLI 服务商；处理答复时发送相关候选、答复与来源片段。按你服务商的数据政策与计费处理。

后台从不替你写

后台提取不能写入正式提醒事项或日程，也不能对外发消息。正式写入必须经过预览和你的确认。

不会重复建

写入与通知都留有持久回执；结果不明时保留待核对，而不是盲目重建。

来源当作不可信

来源片段一律视为不可信的观察，即使里面有看起来像指令的文字。

随时停下

hook-stop 停止活动订阅，workbench-stop 停止工作台；Computer History 本身的设置不受影响。

Install

五分钟装好。

下载 app Apple Silicon

  1. 从 v0.5.0 发布页 下载 Getting-Things-Done-v0.5.0-macos-arm64.zip。
  2. 解压，首次打开前把 Getting Things Done.app 移到 ~/Applications。
  3. 打开 app。app 为 ad-hoc 签名、未公证；若被拦截，在「系统设置 → 隐私与安全性」里选择「仍要打开」。
  4. 需要 Codex 对话技能时，再运行：
python3 -B "$HOME/Applications/Getting Things Done.app/Contents/Resources/skill/scripts/install.py"

从源码安装 Intel 也可用

git clone https://github.com/zgdllt/Getting-Things-Done.git
cd Getting-Things-Done
python3 scripts/install.py
python3 ~/.codex/skills/personal-gtd/scripts/gtd.py workbench

准备好后授权并读取当前清单（doctor 不请求权限，授权也不等于批准任何任务）：

python3 ~/.codex/skills/personal-gtd/scripts/gtd.py doctor
python3 ~/.codex/skills/personal-gtd/scripts/gtd.py authorize
python3 ~/.codex/skills/personal-gtd/scripts/gtd.py snapshot

需要

  • macOS 14+，预编译版面向 Apple Silicon
  • Python 3.11+，Homebrew 版本会被自动识别
  • Codex CLI，已登录你选择的模型服务商
  • Computer History 插件，由你自行开启，用于自动收集；不开启也能手动收集与使用工作台
  • 提醒事项、日历与通知权限，由 macOS 在你启用时请求

开启自动收集：在 Codex 里询问 Computer History 的 eventStreamRootPath，再运行 gtd.py hook-start --root '<返回的路径>'。完整说明见 README。
