Principles · 设计原则

线索，不是承诺。

01

观察只是线索

记录什么由你在 Computer History 中决定：可排除应用与网站，随时暂停。线索不会自动变成任务，更不会被当作“已完成”。

02

工作台留在本机

服务只监听 127.0.0.1，候选与回执存在你的 Mac 上。整理线索时，相关摘录会发给你在 Codex 中配置的模型。

03

系统清单为准

正式任务在提醒事项，时间安排在日历。后台从不替你写入。
