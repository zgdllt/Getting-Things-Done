# Getting Things Done v0.4.0

This release makes the GTD workbench independent of a single activity source. Computer History remains the current automatic adapter, while local Markdown memories provide time-matched summaries and related older clues.

## Highlights

- Added a pluggable clue-source boundary in `scripts/gtd_sources.py`.
- Added local Skysight Markdown memory summaries as a second source.
- Added automatic recall of up to four older summaries related to the current activity.
- Covered raw activity is kept out of the model request when a local summary covers the same interval.
- Marked recalled evidence as historical context in the clarification UI.
- Replaced the implicit fixed timezone with the system IANA timezone, including migration of the old `Asia/Shanghai` default.
- Persisted capture and clarification drafts across workbench reloads.
- Added source health and possible 36-hour gap warnings to the workbench.
- Added source adapter documentation and release packaging coverage.

## Downloads

- **Getting-Things-Done-v0.4.0-macos-arm64.zip** — macOS 14+ Apple Silicon app with the precompiled EventKit bridge. Python 3.11+ is required; Xcode is not required for this download.

## Data boundary

Memory recall runs locally and only selected summaries are sent to the configured Codex provider for background extraction. A historical clue can suggest a connection, but it cannot create a formal Reminder or Calendar event without user confirmation. Formal task state remains in Apple Reminders and fixed-time arrangements remain in Apple Calendar.
