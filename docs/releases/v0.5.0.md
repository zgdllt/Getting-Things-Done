# Getting Things Done v0.5.0

Today and Clarify now open as swipeable cards, with the original list layout available in Settings. Task completion, dismissal, saved answers and restore acknowledgements share a short, nonblocking confirmation: hold for **0.4 seconds**, then fade out over **0.3 seconds**.

## Highlights

- Navigate cards with touch, horizontal trackpad gestures, arrow buttons or the keyboard.
- Keep drafts, selected candidates and the current task across navigation, refresh and style changes.
- Continue interacting while success markers fade. Repeated actions replace the old marker and restart the success toast.
- Retain readable error feedback and support reduced-motion settings.
- Recover from a failed page refresh after a successful write without repeating the write.
- Include a standalone Bilibili Toy demo with synthetic data, shared card code and content-hashed assets. It uses no model service or Apple account access.
- Preserve an explicitly configured local workbench service when updating the native app, while downloaded apps use their bundled service by default.

## Downloads

- **Getting-Things-Done-v0.5.0-macos-arm64.zip** — macOS 14+ Apple Silicon app with the precompiled EventKit bridge. Requires Python 3.11+; Xcode is not required.
- **Getting-Things-Done-v0.5.0-source.zip** — matching source, tests and documentation.
- **Getting-Things-Done-v0.5.0-Toy-demo.zip** — standalone synthetic-data web demo.
- **SHA256SUMS** — checksums for all three archives.

Existing private inboxes, model settings and Apple Reminders/Calendar data remain in their existing locations. The desktop app is ad-hoc signed and is not notarized.

## Verification

Release validation uses isolated Python tests, the workbench and card/Toy browser scenarios, native compilation and strict code-signature checks. The moved-app check serves the archive's own UI resources and checks the 0.4-second hold and 0.3-second fade in the actual WKWebView. Test data is synthetic; no real model calls or Apple task writes are needed.

Physical mobile-device acceptance and notarization are outside this release's verification.
