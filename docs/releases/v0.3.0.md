# Getting Things Done v0.3.0

This release adds a configurable GTD model and immediate answer processing to the native macOS workbench and Codex skill.

## Downloads

- **Getting-Things-Done-v0.3.0-macos-arm64.zip** — the macOS app for Apple Silicon, including the updated Python skill sources and precompiled EventKit bridge. Requires macOS 14+ and Python 3.11+; Xcode is not required for this download.
- **Getting-Things-Done-v0.3.0-source.zip** — the matching source checkout, install script, tests and documentation. Intel users can build from source.
- **SHA256SUMS** — SHA-256 checksums for both archives.

## What's new

- Added a bottom-left **Settings** entry for model selection, reasoning strength, background/notification status and Calendar/Reminders permission status.
- Defaulted GTD model calls to **`gpt-6.1-terra / high`** while preserving the existing Codex provider, login and ordinary chat defaults.
- Added a local model catalog and an option to enter another provider-supported model ID.
- Added durable immediate answer jobs: saving a clarification answer returns immediately, then updates the candidate with a response, revised next action or focused follow-up question without waiting for the Computer History backlog.
- Added failure recovery and retry for answer processing, including standalone questions and jobs that survive a workbench restart.
- Added stale-result protection so late history analysis cannot overwrite a newly saved answer or reintroduce an obsolete question.
- Kept formal Reminders and Calendar writes behind the existing explicit confirmation and receipt flow.

## Verification

The source update passed 44 isolated tests, JavaScript syntax checks and the browser fixture. The browser fixture covers the Settings menu, model persistence, immediate answer feedback, automatic result rendering, model failure retry and mobile layout. The macOS CI job builds and signs both native components and audits the portable archive.

Real-provider checks used only synthetic candidates and produced zero formal system writes. The release does not contain personal history, tasks, tokens or account configuration.

This release is ad-hoc signed and not notarized. Intel Macs can use the source archive to build locally. The interface is currently Chinese and planning dates default to Asia/Shanghai.
