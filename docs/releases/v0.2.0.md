# Getting Things Done v0.2.0

The first downloadable preview of Getting Things Done: a native macOS GTD workbench, a Codex skill and an activity-driven clarification queue.

## Downloads

- **Getting-Things-Done-v0.2.0-macos-arm64.zip** — the macOS app for Apple Silicon, including its Python sources and precompiled EventKit bridge. Requires macOS 14+ and Python 3.11+; Xcode is not required for this download.
- **Getting-Things-Done-v0.2.0-source.zip** — the matching source checkout, install script, tests and documentation. Intel users can build from source.
- **SHA256SUMS** — SHA-256 checksums for both archives.

Unzip the app, move it to `~/Applications` before the first launch, and open it. A supported Homebrew Python is detected automatically. The app is ad-hoc signed and has not been notarized; macOS may require the standard Privacy & Security approval for this downloaded app.

## Included

- Today, Clarify, Projects & Waiting and Review views.
- Native WKWebView window, Dock icon, clipboard integration and source links.
- Specific event summaries and questions in notifications, with a route back to the app.
- Computer History event-file subscription, durable candidates and centralized clarification.
- Apple Reminders/Calendar reads, explicit write previews and idempotent receipts.
- Portable app resources, precompiled native bridge, signature-preserving Python startup and local-service recovery.
- README app icon and installation instructions.

Codex CLI and your chosen model/provider are required for background extraction; the Computer History plugin must be enabled separately. Model extraction sends selected observations and list context to that configured provider. Nothing in this release contains the author's history, task database, tokens or account configuration.

The current interface is Chinese and planning dates default to Asia/Shanghai. This is an early preview. Calendar/Reminders access and notifications still require the normal macOS permissions.

## Verification

The release process checks isolated state transitions, browser interaction, portable app resources, architecture/deployment targets and ad-hoc signatures. Checksums are provided so downloaded assets can be compared with the published files. The app has been built and exercised on Apple Silicon; Intel runtime behavior is not claimed by this binary release.
